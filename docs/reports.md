# 보고서 트랙 (AI·디지털 보고서)

국내 뉴스(`main.py`)·해외 영문(`foreign.py`)과 **파일·실행·한도가 모두 분리된** 세 번째 트랙이다.
기관이 공개한 보고서 중 AI·디지털 주제를 모아 `output/reports.html`로 보여 준다.

| 항목 | 내용 |
|---|---|
| 코드 | `reports.py`(수집·선별·저장), `reports_translate.py`(해외 항목 번역), `reports_page.py`(페이지) |
| 설정 | `config.yaml`의 `reports:` — 수집원 목록과 조회 기간 |
| 저장 | `reports/data/reports.json` (누적·지우지 않음). 로컬에서 돌리지 말 것(Actions가 커밋) |
| 실행 | GitHub Actions **AI·디지털 보고서**(`reports.yml`, 매일 KST 08:00 한 번) 또는 Run workflow |
| 비용 | 요약은 하지 않는다. Groq·네이버 한도를 쓰지 않는다. **해외(영문) 항목 번역에만 구독 Claude**(`CLAUDE_CODE_OAUTH_TOKEN`, 해외 영문 뉴스와 같은 토큰)를 쓴다 — 항목당 1회, 새 항목만 |
| 국내 페이지 | 파일이 있을 때만 `보고서 ↗` 링크가 걸린다(`html_generator.py`) |

로컬에서 시험할 때는 저장소 데이터를 건드리지 않게 따로 돌린다:
```
venv/bin/python reports.py --data-dir /tmp/rdata --out /tmp/reports.html [--only fsec,kpmg] [--lookback 30]
```

## 수집원 유형 (`type`)

| type | 읽는 곳 | 쓰는 기관 |
|---|---|---|
| `fsec` | 게시판 목록 JSON(`/bbs/list`) | 금융보안원 |
| `fsc`·`fss` | 서버가 그려 주는 보도자료 목록(쪽 넘김) | 금융위원회·금융감독원 |
| `rss` | RSS/Atom(여러 피드는 `urls`) | 한국은행·BIS·FSB·BoE·ECB·ESMA·EBA·연준·뉴욕연준 |
| `sitemap` | 사이트맵(주소+수정일) → 새 주소만 상세 메타 | 삼정KPMG |
| `ey` | 목록 카드 → 새 주소만 상세 메타 | EY한영 |
| `table` | 표 형태 게시판(설정으로 선택자 지정) | 개인정보위·KB경영연구소 |
| `kcmi`·`kisa`·`nia` | 기관별 목록 | 자본시장연구원·KISA·NIA |
| `msit` | 과기정통부 보도자료 — 목록 쪽 안의 스크립트에서 제목·날짜를 읽음 | 과학기술정보통신부 |
| `spri`·`kisdi`·`kiri`·`wfri`·`hana` | 서버가 그려 주는 카드·목록(기관별 어댑터) | 소프트웨어정책연구소·정보통신정책연구원·보험연구원·우리금융경영연구소·하나금융연구소 |
| `bing` | Bing News RSS — 기관 사이트를 직접 못 읽을 때 **발간 보도**만 | PwC·금융연구원·NH금융연구소·IMF·McKinsey 등 |

`kind`: `보고서`·`정책발표`·`보도`·`press`(보도자료 — 제목에 보고서·가이드라인·로드맵·실태조사 등이 있으면 보고서, 아니면 정책발표).
`finance: true`면 그 기관 항목 전부 '금융 관련', 아니면 제목·설명에 금융 단어가 있을 때만.
**조회 기간은 전역 `reports.lookback_days: 180`(6개월) 하나**로 모든 수집원에 같이 적용한다. 페이지도 이 기간 이내만 보여 주고(저장소 `reports.json`에는 남는다), 수집원에 `lookback_days`를 따로 적으면 그쪽이 우선한다.
**`reports.exclude_kinds: [정책발표]`** — 이 구분은 싣지 않는다. 제목에 보고서·가이드라인·실태조사 같은 말이 없는 보도자료(정책 발표)는 제외 기록에 `정책발표는 싣지 않음`으로 남는다. 정책 발표도 보려면 `[]`로 비운다. `보도`(검색으로 잡은 발간 소식 기사)도 빼려면 `[정책발표, 보도]`.

새 수집원 추가: 목록 주소와 날짜 모양이 서버 렌더링이면 `table`(설정만), 아니면 `reports.py`에 `fetch_*` 어댑터를 만들고 `ADAPTERS`에 등록.

## 선별 규칙

1. **핵심어**(`_CORE_KO`·`_CORE_EN_RX`: AI·인공지능·생성형·에이전트·디지털·클라우드·블록체인·스테이블코인·핀테크·마이데이터·양자·망분리…)가 **제목에** 있어야 통과. 설명에만 있는 말(한국은행 요약문 속 'AI')은 근거가 아니다.
2. **제외 주제**(`_EXCLUDE_TOPIC_RX`): 양자내성암호·양자암호통신·양자키·PQC·post-quantum 등 암호·보안 쪽 양자 이야기는 핵심어가 있어도 뺀다(`제외 주제` 사유로 남음). 양자컴퓨터·양자 기술은 남긴다.
2. **일부러 뺀 말**: 보안·개인정보·보이스피싱·해킹·사이버·전자금융·ICT·결제·플랫폼·데이터·로봇·자동화·비대면·가상자산. 그 말만 있는 글(개인정보위 인사발령, 보이스피싱 주의보, ICT 수출입 동향)이 목록의 절반을 채워 뺐다. 제목에 AI·디지털이 같이 있으면 그 단어로 통과한다. 되살리려면 `_CORE_KO`에 더한다.
3. 영문 약어(AI·LLM·GPU…)는 **앞뒤가 영문자가 아닐 때만** — `KAIST`·`AIA`·`MAIN`에 걸리지 않는다.
4. `bing` 수집원은 추가로 `need`(보고서·발간·설문 등) 단어가 **제목에** 있어야 하고(설명에만 있으면 제외 — 실적·제휴·인사 기사가 섞인다), 제목 끝이 `: Report`이면('…라고 보도') 제외하며, `must`(기관명)가 있어야 한다. 기관 보고서가 아니라 **기사**이므로 `보도` 구분으로 표시한다.
5. 걸러진 항목은 **사유와 함께 `dropped`에 남고** 페이지 맨 아래에 보인다(최대 400건 표시). 어떤 항목도 조용히 사라지지 않는다.
6. 다른 기관이 같은 제목으로 낸 것(금융위·금감원 공동 보도자료, FSB 보도자료+간행물)은 한 장으로 합치고 `함께 게시`로 남긴다(14일 안, 보고서 > 정책발표 > 보도 순 대표).

## 해외 항목 번역 (`reports_translate.py`)

제목에 한글이 없는 항목(BIS·연준·ECB·IMF·맥킨지 등과 그 발간 소식 기사)의 **제목·설명**을 한국어로 번역한다.

- **구독 Claude만**(`claude -p`, `reports.translate.model`: sonnet). Groq·API 키를 쓰지 않는다(`check.sh`가 `GROQ_API_KEY`·`ANTHROPIC_API_KEY` 문자열을 막는다). `reports.yml`이 CLI를 설치하고 토큰을 넘긴다.
- **항목 1건 = 호출 1회**(제목+설명). 묶어 부르지 않는다 — 요약 배치 금지와 같은 이유(일부를 조용히 빠뜨린다).
- **원문은 바꾸지 않는다.** `title_ko`·`desc_ko`를 따로 저장하고 카드에 원제를 작게 같이 보인다. 새 항목만 번역하고, 제목·설명이 바뀐 항목은 다시 번역한다.
- **검증**: 한글이 있어야 하고, 번역문의 영문 단어는 원문에 있던 것이어야 하며(지어낸 고유명사·약어 차단), 31보다 큰 수치는 원문에 있던 숫자여야 한다(단위 환산 `250 billion → 2,500억`은 같은 수로 본다). 설명 길이가 원문의 0.2~2.5배를 벗어나면 요약·덧붙임으로 보고 버린다. 통과 못 하면 번역을 붙이지 않는다 — 카드에 `번역 전` 표시와 함께 영문 그대로 보인다(항목당 최대 2번 시도).
- **실패해도 수집은 계속된다.** 토큰이 없거나 구독 한도가 소진되면 그 실행의 번역만 건너뛴다(영문 표시, 시도 횟수는 쓰지 않음). 한 실행 최대 80건·720초(`max_per_run`·`max_seconds`) — 첫 실행처럼 많으면 남은 것은 다음 실행(다음 날 아침 8시)에서 이어서 번역한다. 급하면 Run workflow로 바로 한 번 더 돌린다.
- 끄려면 `reports.translate.enabled: false`.

## 지켜야 할 것

**봇 차단(403 등)을 우회하지 않는다.** 삼일PwC·IMF·세계경제포럼·BCG·베인은 일반 요청에 403을 돌려준다. 브라우저인 척 헤더를 꾸미거나 재시도로 뚫지 않는다(`check.sh`가 `Sec-Fetch` 문자열을 막는다). 막힌 곳은 `bing` 보도 수집원으로 대신하고, 수집원 실패는 페이지 아래 **수집원 상태**에 사유와 함께 남긴다.

**403·404·410은 재시도하지 않는다.** 같은 결과이고 서버에 부담만 준다(`_get`).

**수집원 하나가 전체를 멈추지 않는다.** 어댑터 예외는 `_run_source`가 그 수집원의 실패로만 기록한다.

**날짜를 모르면 처음 본 날로 두고 `(수집일)`로 표시한다.** EY한영은 `firstpublishdate`가 섹션 전체 같은 날(2025-03-19)이라 쓰지 않고 `dateuser`(페이지 수정일)를 쓴다.

**쪽 넘김 수집은 이미 본 쪽에서 멈춘다.** 금융위·금감원은 한 쪽 전체가 `known`(저장된 항목+제외 기록)이면 멈춘다 — 매 실행 수십 쪽을 다시 읽지 않는다. 그래서 **제외 기록은 가장 긴 조회 기간만큼 보관**한다(더 일찍 지우면 사이트맵류가 같은 주소를 매번 다시 읽는다).

**금융연구원 목록은 읽지 않는다.** `/kif4/biz/async_proc?ac=dataSearch`가 일반 요청에는 빈 결과(`{"result": ""}`)를 주고 브라우저의 AJAX 요청에만 답한다. 머리글을 브라우저처럼 꾸며야 읽히는 구조라 우회하지 않는다 — Bing `보도`로만 잡는다. NH금융연구소는 접속 가능한 사이트 주소를 찾지 못해 같은 방식이다. 둘 다 **기관이 쓸 수 있는 공개 피드·API를 열어 주거나 주소를 알게 되면** 어댑터를 만든다.

**한국 기관 사이트는 해외 서버(Actions)의 접속을 막을 수 있다.** 로컬에서 되는 것이 Actions에서 되는 것을 보장하지 않는다. 첫 실행 뒤 **수집원 상태**에서 ✗가 있는지 먼저 볼 것.

## 자료 읽는 법

- 카드의 `일치 단어`는 선별을 통과시킨 단어다. 엉뚱한 단어면 `_STRONG_KO`를 의심한다.
- `보도` 구분은 기관의 보고서가 아니라 발간을 알린 기사다. 원문 링크가 기사 주소다.
- 같은 보고서를 여러 매체가 다루면 `보도` 카드가 여럿 나온다(제목이 달라 합쳐지지 않는다).
